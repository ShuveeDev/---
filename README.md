# Програма «Розміри типів даних»

Програма виводить, скільки байт пам'яті займають базові типи даних мови C:
`char`, `int`, `float`, `long int`, `long double`.

## Компіляція та запуск

```bash
gcc -o main main.c
./main
```

Якщо бажаєте компілювати без створення окремого файлу виконуваного файлу:

```bash
gcc main.c -o main && ./main
```

## Приклад виводу

```
Дані типу char займають 1 байт.
Дані типу int займають 4 байт.
Дані типу float займають 4 байт.
Дані типу long int займають 8 байт.
Дані типу long double займають 8 байт.
```

> Розміри типів залежать від платформи та компілятора й можуть відрізнятися на інших системах.
